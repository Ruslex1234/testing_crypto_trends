Hourly decision scorecard

Every run, each strategy decides to be in, be out, or change nothing. The next runs score that decision with prices it couldn't see. Follow = what obeying the strategy earned; Opposite = what doing the reverse earned (out when it was in, in when it was out).

Scenario log

Each strategy publishes the price levels it is watching (entry triggers, take profits, grid lines, breakouts). Every run checks the real 5 minute highs and lows since the last run; a level that was crossed is logged, then re-checked 24h later.

Stop scorecard

Every stop-out is re-checked 24h and 72h later. Price lower afterwards = the stop saved money; higher = it cost money (a whipsaw).
